## Week 1 (Days 1–7): Core pipeline

### Day 1 — Scaffold
- [ ] Create Next.js 14 app (App Router, TypeScript, Tailwind, shadcn/ui)
- [ ] Set up Supabase project, copy DATABASE_URL
- [ ] Write Prisma schema: `emails`, `email_ips`, `email_domains`, `email_urls`, `campaigns`, `email_campaigns`
- [ ] `prisma migrate dev` — verify all tables created
- [ ] `.env.local`: `HF_TOKEN`, `IPINFO_TOKEN`, `ABUSEIPDB_KEY`, `DATABASE_URL`, `NEXT_PUBLIC_APP_URL`
- [ ] Deploy skeleton to Vercel, verify env vars propagate

### Days 2–3 — SSE foundation + email parsing
- [ ] `POST /api/analyze` — SSE setup: `ReadableStream`, headers `Content-Type: text/event-stream`
- [ ] `mailparser` integration: parse raw .eml → extract all `Received` hops, `Authentication-Results`, `from`, `messageId`, body
- [ ] Input validation: reject > 500KB; 422 if `from` or `messageId` missing
- [ ] SPF/DKIM/DMARC status: parse `Authentication-Results` header (pass/fail/none per auth type)
- [ ] URL extraction from body via regex (capture http/https links)
- [ ] Emit SSE event: `{"step":"headers","status":"done","hopCount":N,"spf":"fail","dkim":"pass","dmarc":"fail"}`

### Days 3–4 — Geolocation
- [ ] Private IP detection: skip RFC 1918 (10.x, 192.168.x, 172.16-31.x) and loopback in hop list
- [ ] `Promise.all(publicIps.map(ip => fetch(ipinfo.io)))` — parallel, typed response
- [ ] Store IP data (do not persist yet — accumulate for later DB write)
- [ ] Emit SSE event: `{"step":"geolocation","status":"done","hops":N}`

### Days 4–5 — HuggingFace classifier
- [ ] `fetch` HuggingFace Inference API: `facebook/bart-large-mnli`, zero-shot labels `["phishing","legitimate"]`
- [ ] Handle cold-start timeout: if HF returns 503, retry once after 3s; if still 503, mark score as `null` ("unavailable")
- [ ] Emit SSE event: `{"step":"classification","status":"done","score":0.87}` (or `"status":"unavailable"`)

### Days 5–6 — Scoring + DB write
- [ ] WHOIS cache: check `email_domains` by domain + `whois_checked_at` TTL (7 days) — call `whoiser` only on miss
- [ ] AbuseIPDB cache: check `email_ips` by IP + `abuse_checked_at` TTL (7 days) — call API only on miss
- [ ] Fraud score computation (pure function — test this first):
  - SPF fail: +20 | DKIM fail: +20 | DMARC fail: +15
  - Domain < 30 days old: +20
  - HF phishing score > 0.7: +15
  - AbuseIPDB score > 50: +10
  - Cap at 100. SPF+DKIM+DMARC all fail → floor to 40
- [ ] Prisma transaction: write `emails`, `email_ips`, `email_domains`, `email_urls` atomically
- [ ] Emit SSE event: `{"step":"complete","emailId":"<uuid>","verdict":"Fraudulent","score":82}`
- [ ] Close SSE stream

### Day 7 — Results UI
- [ ] Client-side SSE consumer: `fetch` + `response.body.getReader()` (NOT native `EventSource` — it doesn't support POST)
- [ ] Live progress display: step badges updating as events arrive
- [ ] Final verdict card: score, label (Legitimate/Suspicious/Fraudulent), color-coded
- [ ] Relay hop table: IP, country, ASN, org per hop
- [ ] Error state: if stream closes with error event, show error message
