Fraud Score Engine 09 / 13 EmailThreat

A weighted five-signal fraud score classifies emails as Legitimate, Suspicious, or Fraudulent — each layer contributes independently

Score = SPF(20) + DKIM(20) + DMARC(15) + DomainAge(20) + HFClassifier(15) + AbuseIPDB(10)   |  max = 100
Legitimate
Score 0 – 39
Low risk. Minor signals present
but no strong indicators.
Suspicious
Score 40 – 59
Multiple signals triggered.
Manual review recommended.
Fraudulent
Score 60 – 100
Strong multi-signal consensus.
Block and investigate.
Triple-auth-fail floor rule
If SPF + DKIM + DMARC all fail → score = max(40, computed_score)
Guarantees at least Suspicious verdict. Prevents clean IP from masking unauthenticated sender.
Signal independence
Signals are additive and independent. Spear-phish with valid DMARC still scored by AI + domain age + AbuseIPDB. No single signal required to reach Fraudulent.
Deduplication
SHA-256 hash of raw .eml detects duplicates. Same email resubmitted returns cached result instantly — no re-analysis, no API calls.
